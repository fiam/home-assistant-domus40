# Integration artwork

The Domus40 integration mark is original AI-generated artwork created on
2026-08-30 with OpenAI's built-in ImageGen tool. No source or reference images
were supplied. It does not incorporate EFAPEL, Domus40, Home Assistant, or
other third-party logos, product artwork, screenshots, or device silhouettes.

The source and derived files are:

- `domus40-icon-source.png`: 1024 × 1024 RGBA source.
- `icon.png`: 256 × 256 RGBA integration icon.
- `icon@2x.png`: 512 × 512 RGBA high-density integration icon.

The 256px and 512px files are also copied to
`custom_components/domus40/brand/`, the repository location consumed by HACS.

The generated asset is distributed under the repository's MIT license.
