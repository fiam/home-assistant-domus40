# Security policy

Only the latest tagged release and current `main` branch receive security
fixes.

Report vulnerabilities through a private GitHub Security Advisory when that
facility is available. Otherwise contact [@fiam](https://github.com/fiam)
privately. Do not open a public issue containing credentials, tokens, cookies,
network addresses, device identifiers, captures, Home Assistant storage, or
details that would expose a specific installation.

If a secret was exposed, revoke or rotate it before reporting the incident.
Include the integration version, Home Assistant version, affected interface,
impact, and sanitized reproduction steps. You should receive an acknowledgement
within seven days; disclosure timing will be coordinated after a fix exists.
